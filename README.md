# Kudi

A simple budget tracker for students in Ghana — log income and spending, set limits, see where your cedis go.

## Features
- Log income and expenses by category
- Set a weekly or monthly budget limit with a live meter
- Category breakdown chart and weekly summary
- Saves to your device (localStorage)

## Run it
Open `budget.html` in any browser.

## Built with
Plain HTML, CSS, and JavaScript — no frameworks.
